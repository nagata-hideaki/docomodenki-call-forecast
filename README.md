# 📞 ドコモでんきコール予測アプリVer1

コンタクトセンターの日別コール数を予測するアプリです。

## 特徴

- LightGBM v18.2 による高精度予測
- MAPE 5〜10% 台の実運用レベル
- 4カテゴリ別モデル + Bias補正 + log変換
- GW前後分割特徴量

## 使い方

1. 履歴データ（TSV/CSV）をアップロード
2. 予測対象年月を選択
3. 予測結果を CSV でダウンロード

## モデル情報

- 学習データ: 25ヶ月分
- 特徴量: 曜日、月初/月末、GW前後、契約者数、新規販売数など
- 精度実績:
  - 4月: MAPE 5.21%
  - 5月: MAPE 10.19%
  - 6月: MAPE 5.44%
